---
name: Style d'enseignement validé
description: Comment enseigner efficacement à cet utilisateur
type: feedback
---

L'utilisateur préfère l'approche "Option A" : il code lui-même, Claude guide et corrige.
Ne pas écrire le code à sa place sauf s'il le demande explicitement (fatigue, fin de session).

**Why:** l'utilisateur veut apprendre en pratiquant, pas juste recevoir du code.
**How to apply:** expliquer le concept, donner la mission, attendre son implémentation, puis corriger/valider.
