Jeu en développement : deckbuilder roguelite cyberpunk en JavaScript Vanilla.
GDD disponible dans : `documentation/gameDesignDocument.md` (projet Algo A Star).

Le projet jeu sera dans un dépôt/dossier **séparé** du projet Algo A Star.

**Why:** l'utilisateur veut garder le projet Algo A Star comme espace d'exploration des algorithmes. Les algos appris ici (BSP, Voronoi, A*, BFS...) seront réutilisés dans le jeu, mais dans un projet distinct.

**How to apply:** ne pas mélanger les deux projets. Quand on travaille sur Algo A Star, rester dans la logique d'apprentissage. Le GDD sert de référence pour comprendre *pourquoi* certains algos sont étudiés, pas comme spec à implémenter ici.
